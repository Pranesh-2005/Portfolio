Assessment Platform

  • Tech Stack: HTML, CSS, JavaScript, Python (Flask), PostgreSQL, Render
  • Website URL: Live Demo
  • GitHub URL: Project Repository

A full-stack assessment platform built to streamline online testing for students and faculty. Developed using HTML, CSS, JavaScript for the frontend and Python (Flask) with PostgreSQL on the backend. Deployed using Render.

Students can register, log in, book slots, take assessments with various question types (MCQ, Short Answer, Match, Programming), view results, and manage their profiles.

Faculty can create/edit/delete assessments and questions, monitor results, and update their profiles. The platform ensures ease of use with role-based access and responsive UI.
