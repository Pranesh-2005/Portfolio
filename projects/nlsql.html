NL2SQL-SQL2NL

  • Tech Stack: Transformer, NLTK, HTML, CSS, Python, PostgreSQL, Flask
  • Github URL: Project Link

Developed an NLP to SQL and SQL to NLP system that enables users to interact with databases through natural language. The system converts user queries in natural language into structured SQL queries for database retrieval and transforms SQL results back into readable natural language for easier understanding.

Fine-tuned a pre-trained language model to handle the conversion tasks, ensuring high accuracy and efficiency. Integrated query optimization techniques and semantic parsing to improve the system's performance in real-time database interactions.

Collected and preprocessed diverse natural language and SQL query datasets, refining the model's ability to handle complex queries. Achieved a significant improvement in query accuracy and natural language generation by enhancing the model with additional fine-tuning and data pipeline adjustments.
