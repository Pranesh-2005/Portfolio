Emotion Detection in Text using BERT

  • Tech Stack: Python, HTML, CSS, JavaScript, BERT
  • GitHub URL: Project Link

Developed a web-based application for detecting and classifying emotions in user-generated text using BERT (Bidirectional Encoder Representations from Transformers).

Fine-tuned a pre-trained BERT model on a large emotion-labeled dataset to improve detection accuracy across multiple emotion categories such as joy, anger, sadness, and neutral. Achieved significant accuracy gains over traditional sentiment models.

Integrated the model into an interactive interface using Jupyter Notebook and evaluated performance using precision-recall metrics. Enabled real-time emotion detection for user inputs, paving the way for improved NLP-based feedback systems.
