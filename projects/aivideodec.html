AI Generated Video Detector

  • Tech Stack: Python, MTCNN, EfficientNetV2, Hugging Face, Gradio
  • GitHub URL: Project Link

Developed a deep learning-based system to detect AI-generated (deepfake) videos using MTCNN for face detection and EfficientNetV2 for feature extraction and classification.

The pipeline uses MTCNN to accurately detect faces in video frames, followed by analysis via a fine-tuned EfficientNetV2 model to determine whether the content is real or synthetic.

The model was integrated into a Gradio interface for interactive, real-time detection, allowing users to upload or stream video for instant results.
