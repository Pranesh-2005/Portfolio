Chrome Extension for Translation

  • Tech Stack: Python, Flask, HTML, CSS, JS, Deep Translate
  • Github URL: Project Link

Developed a Chrome Extension for real-time translation that uses DeepL Translation API and integrates seamlessly with the browser. The extension allows users to translate selected text on any webpage with a single click, making it easy to switch between multiple languages.

Built the extension using HTML, CSS, and JavaScript for the frontend, while Python (Flask) served as the backend for processing translation requests. Integrated the DeepL Translation API to provide accurate and high-quality translations.

Implemented a clean and user-friendly interface with features like language selection and automatic detection of source text. Ensured smooth interaction and fast translation response times by optimizing both the frontend and backend components.
